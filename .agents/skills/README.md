# Skills des Roboter-Generators

**Skill = dauerhaftes Wissen und Arbeitsweise, Prompt = die konkrete Aufgabe.** Format wie bei Cube Escape
(offenes Agent-Skills-Format, `.claude/skills` ist ein Link auf diesen Ordner). Kern für jede Aufgabe: `AGENTS.md`.

| Skill | Wofür |
|---|---|
| `rg-unity-testbed` | Unity-Testpaket ausführen, erweitern, beschleunigen; Unity-Vorlagen (Shader, Look, Appearance) |
| `rg-unity-integration` | Übergabe an das Spiel: welche Dateien und Daten, wie Unity sie nutzt |

Pflege: ein Skill bleibt unter 150 Zeilen; veränderliche Zahlen nicht festschreiben, sondern den Ort nennen;
neue Falle genau in den Skill ihres Bereichs.
