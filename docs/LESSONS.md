# Lehren

- Sperre vor dem Pausieren nehmen; `check_output.sh` enthält Unity und Blender: `./ce lock <Ressource> -- <Befehl>` je Ressource ([Hintergrund](TECHNIK.md)).
- Geteilte Caches nur atomar schreiben; Code-/Bake-Schema bei nicht erfassten Änderungen heben ([Hintergrund](TECHNIK.md)).
- IDs von Clips, Skins und Formen bleiben erhalten; bestehende Spiel-Clips nicht nebenbei ändern ([Regeln](../AGENTS.md)).
- Blender-/Viewer-Prüfung ersetzt keine Unity-Abnahme ([Hintergrund](TECHNIK.md)).
